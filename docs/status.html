The product

Two surfaces on one engine

Launch
Underwrite

Launch lets anyone stand up a rolling Event Contract series for any asset the Somnia oracle already feeds. Underwrite is the vault behind it: deposit tUSDC, receive shares, and the vault manufactures complete sets and rests both sides of every window it launches.

The two are one product. A market nobody quotes is a market nobody can trade, so a launchpad that cannot also make its own markets ships an empty book. Keel's markets are born quoted.

Quoting against the incumbent on its own BTC and ETH windows loses money across every parameter tested, twice, including with the designed defences switched on.

No cell reaches break-even. Defence 3 — the leftover-leg unwind the design called for — makes things worse at its default and is reported that way rather than tuned away.

The diagnosis, measured. 122 of 271 recorded trades — 45.0% — executed at or inside fair value plus 0.015: prices we could never have been crossed at. The incumbent's median implied half-spread is 0.0184 across all trades and 0.0150 on Up-buys, sitting almost exactly on our own reference markup. We were filled only when we were the worst price on the book.

This does not measure Keel as sole maker on an unserved asset, which has no history and can only be shown live. Both things are true at once, and neither is used to discount the other. What it settles is the strategy: Keel does not compete for BTC and ETH flow. It makes the markets nobody else has made.

Safety

The load line

Built

SpreadPolicy.sol
6 fuzz
properties

Minting a complete set turns one unit of collateral into one Up and one Down at once. Together they are worth exactly one unit at settlement, however the window resolves. So if both legs are sold for more than one unit combined, the outcome cannot touch the vault — it has been paid a markup for a service rather than taking a directional bet.

Three consequences fall out of that, and each removes a class of attack rather than mitigating it:

  • Prices are computed on-chain, not accepted. The hot key supplies a fair value and a size; the contract decides the prices. A stolen quoter key can quote badly. It cannot quote at a structural loss, and it cannot withdraw at all.
  • Share price is struck only when the vault is flat. Anything markable is gameable, so the vault runs in epochs and refuses to strike a price while any order or position is open. There is no mark to attack because there is no mark.
  • The exit never touches the operator. Orders die at the window's own expiry, expired escrow is reclaimable by anyone, settled positions are redeemable by anyone, and rolling the epoch is permissionless. If the quoter key goes dark, a depositor waits out one window and drives the whole exit themselves — a path with its own test.

contracts/src/KeelVault.sol

Built

The underwriting vault. Epoch-based deposits and redemptions, on-chain quote construction, complete-set mint and burn, order placement and cancellation, settlement redemption, and a capped high-water-mark performance fee paid in shares. Pool provenance is read from the module, never from the pool — a security review found that trusting the pool turned the hot quoter key into a withdrawal key. Dead shares close the two-roll share-inflation attack the epoch design does not close on its own. 36 tests.

contracts/src/KeelFactory.sol

Built

Keel's control plane. Registers its own operator, creates its own venue, mints its own market creator and allowlists it — one transaction or none, because a half-run leaves a venue that reads as live and refuses every roll. Launching is permissionless but priced at the oracle reserve the series will spend, so a launch buys a runway rather than one window. Series ids are allocated here and never reused. Launching is priced per unit of runway rather than per roll, so a fast-cadence series cannot starve the shared creator float. rearm restarts a series whose roll loop has stranded. 38 tests.

contracts/src/lib/SpreadPolicy.sol

Built

Fair value plus state in, two ask prices out. Near-expiry widening scaled as √(refTau/τ), a skew penalty on the side the vault is already long, and the solvency invariant. 24 tests including six fuzz properties.

contracts/src/interfaces/

Built

DreamDEX's BinaryPool, the ERC-6909 outcome singleton, settlement and the markets module. Every signature and selector verified against SDK source and live calls, not guessed.

contracts/test/mocks/

Built

A BinaryPool faithful to the parts Keel depends on — outcome-token escrow on resting sells, best-effort cancellation, lazy expiry, and prices always in Up terms including for the order that sells Down. Plus a settlement, a market, a module and a 6-decimal collateral token.

worker/pricer.js

Built

Pure math, no I/O. The digital-option pricer P(Up) = Φ((S−K)/(σ·S·√τ)) and per-second volatility as RMS log-return. Runs identically in the browser and the back-test.

worker/spreadPolicy.js

Built

A line-for-line mirror of the Solidity policy, tested against the contract's own reference values so the simulation and the chain cannot silently drift apart.

worker/marketmaker.js · mmbacktest.js

Measured

Honest fill modelling against recorded trades: we are filled only when a real trade crossed our resting price. Caches its market pull so a re-run reproduces the same numbers.

worker/backtest.js

Measured

Scores the pricing model's Brier score against a flat-0.5 baseline on settled windows, training σ strictly on ticks before each window opens.

worker/quoter.js

Built

The live loop. Its deciding half is a pure function — every rail that stops a losing quote lives there, where it is tested: an expiry floor, a stale-tick cutoff that cancels rather than widens, requote hysteresis so the loop does not churn queue position for nothing, and a notional ceiling. The live send path is wired: register, mint sets, quote, settle and reclaim, each simulated before it is sent. 85 Node tests.

How to run it

From a fresh clone, two commands get to a green suite. Nothing below needs a private key, testnet funds, or a network connection except where noted.

npm run setupInstalls Node packages, clones pinned Solidity dependencies, creates .env, then runs the doctor. Safe to re-run.
npm testThe whole suite — 85 Node tests and 98 Foundry tests, in about a second.
npm run doctorChecks the environment and prints an exact fix line for anything wrong.
npm run chainstateRegenerates the live market-structure evidence. Network, no wallet.
npm run backtestScores the pricing model against settled windows. Network, no wallet, slow.
npm run mmbacktestReproduces the market-making result in the table above.
npm run webThe console at localhost:5173 — live coverage gap and live pricing, no build step.
npm run quoteThe quoter loop. Dry run by default: it prints what it would rest and sends nothing.
npm run deployPrints the deployment plan and stops. Add -- --confirm to send it; needs a funded key.

Solidity dependencies are cloned at pinned tags rather than committed, so the repository stays small and a green run stays reproducible.
